\section{Genomic dataset formation (OrthoFinder)}
The plugin uses a three-step panel. \textbf{Input} selects a folder of
GBFF/GB/GBK files (one file per organelle genome) or a folder of proteome
FASTA files, and sets the genetic code, pseudogene handling, internal-stop
policy, and output folder. GenBank input is parsed into CDS features,
translated to protein, and written as \texttt{proteomes/<species>.faa},
\texttt{cds/<species>.fna}, and \texttt{cds\_map.tsv}. \textbf{OrthoFinder}
sets the OrthoFinder executable, the BLAST+/MCL directory, the thread count,
and the run mode (full pipeline, parse only, or reuse existing results); the
runtime check reports any missing executable by name. \textbf{Review} shows the
selected input, output, runtime, and run mode before the pipeline starts.

The output tab shows summary cards (species, CDS, orthogroups, single-copy
orthogroups) and a table of single-copy orthogroups. For each single-copy
orthogroup the plugin writes a protein FASTA, an in-frame CDS FASTA, and a
mapping table, so the CDS set can be passed directly to codon-aware alignment
or selection analyses. The pipeline runs in a background thread and streams
the OrthoFinder log to the Console tab; it is not modal.
