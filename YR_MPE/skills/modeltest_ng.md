# ModelTest-NG skill

## Purpose

Select a DNA or protein substitution model and import the best model as a
workspace `model` item. ModelTest-NG evaluates a candidate set and reports
BIC, AIC and AICc in one run.

## Preconditions

- One or more aligned FASTA/PHYLIP files.
- More than three taxa for reliable model selection.
- For a partitioned dataset, model selection currently runs per alignment;
  partition mode (`-q`) is not wired yet.

## GUI to CLI

The plugin's `control_bindings()` is the source of truth. The expected mapping
is:

| GUI control | CLI option | Notes |
|---|---|---|
| File input | `-i`, `--input` | One ModelTest-NG process per selected file |
| Sequence type | `-d`, `--datatype` | `DNA -> nt`, `Protein -> aa`; `Auto` is detected from the first record |
| Criterion | none | GUI-only post-processing; ModelTest-NG always reports BIC/AIC/AICc |
| Starting tree | `-t`, `--topology` | `ML starting tree -> ml`, `MP starting tree -> mp` |
| DNA schemes | `-s`, `--schemes` | `3`, `5`, `7`, `11`; only passed for nucleotide data |
| Threads | `-p`, `--processes` | |
| Output prefix | `-o`, `--output` | Generated by the plugin |
| (fixed) | `--force`, `--disable-checkpoint` | Overwrites results; avoids the Cygwin exit crash |

Verify options with:

```text
modeltest-ng --help
```

## Run and import

1. Select an alignment in the workspace, then open
   `MODEL -> Find Best Substitution Model (ModelTest-NG)`.
2. Choose the criterion used for the exported best model (BIC by default).
3. Run; inspect the criterion tables in Output Preview.
4. Click `Import to Current Platform`. The item data contains
   `type=model_table`, `best_model`, `criterion` and all three criteria tables.
5. Select the model item in the workspace and open
   `PHYLOGENY -> Maximum Likelihood (ML) -> RAxML-NG`; the model is applied
   automatically when possible.

## Pitfalls

- The BIC/AIC/AICc names are not command-line options; they select which block
  is exported.
- ModelTest-NG can exit non-zero after writing a valid report; the plugin
  accepts the report when the `.out` file exists.
- `Auto` is resolved before the command is built; the preview shows
  `<auto: nt|aa>` when it is not yet resolved.
